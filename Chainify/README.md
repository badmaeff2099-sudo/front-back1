# Chainify

Приложение для отслеживания ежедневных действий для достижения целей и создания полезных привычек.

## Описание

Chainify - это простое React приложение, которое помогает участникам отслеживать свой ежедневный прогресс. Каждый участник может отмечать выполнение своего действия за день, и все участники видят прогресс друг друга в виде вертикальных столбцов с квадратиками.

## Функции

- ✅ Отметка выполнения ежедневного действия
- ✅ Визуализация прогресса в виде вертикальных столбцов
- ✅ Отображение прогресса всех участников
- ✅ Сохранение данных в localStorage
- ✅ Адаптивный дизайн

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev сервер:
```bash
npm run dev
```

3. Откройте браузер по адресу, который покажет Vite (обычно http://localhost:5173)

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist`.

## Технологии

- React 18
- Vite
- CSS3
